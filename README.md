# PODVAL — сайт кальян-бара

Многостраничный сайт: главная, о заведении, меню с корзиной, корзина, пример оплаты, бронь стола со схемой
зала, галерея и правила.

Стек тот же, что у CompClub: Next.js 16, React 19, TypeScript, Tailwind CSS 4.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

## Где что лежит

- `src/lib/data.ts` — контакты, часы работы, всё меню с ценами, выгодные позиции, сборы для «Правил», отзывы, фото галереи.
- `src/components/booking.tsx` — бронь: календарь, часы, схема зала (координаты столов в массиве `spots`).
- `src/app/checkout/page.tsx` — пример страницы оплаты. Деньги не списываются: перед запуском её подключают к платёжному сервису.
- `public/photos` — фото зала, `public/menu` — фото позиций из меню restik.

## Что заменить перед запуском

- Бронь сохраняется только в браузере гостя (`localStorage`), занятость столов имитируется. Её нужно подключить к CRM, боту или таблице.
- Оплату — к ЮKassa, CloudPayments или другому эквайрингу.
- Схема зала условная: поправьте столы и вместимость в `spots` под реальный зал.
- Правила «Как у нас принято» написаны как черновик — сверьте с реальными правилами заведения.
